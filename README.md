## Question 1 – Interactive Text Changer
This question uses JavaScript functions and event listeners to change the paragraph text when the user clicks the button.

**Expected output:** The message changes from "Welcome to my website!" to "Hello there!".

## Question 2 – Smart Number Validator
This question uses an if...else if...else structure to validate user input and compare the entered number with 10.

**Test cases:**
- 5 – The number is lower than 10.
- 10 – The number is equal to 10.
- 15 – The number is higher than 10.
- abc – Please enter a valid number!
- Empty input – Please enter a valid number!

## Question 3 – Dynamic Number Generator
This question uses a for loop and DOM manipulation to generate five list items from 1 to 5 when the user clicks the Generate button.

The existing list is cleared before generating new items to prevent duplicate output.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the Q1, Q2 or Q3 folder.
4. Double-click the `index.html` file.
5. Run the webpage using a desktop browser such as Google Chrome.
6. Interact with the buttons to test each question.
